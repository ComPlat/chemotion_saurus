:::info[Permissions]

The system administrator needs to globally configure the UI feature for LabIMotion (generic elements, generic segments, and generic datasets). Otherwise, only users on the allow list will have access to the LabIMotion.

:::

LabIMotion is a versatile software enabling the creation of customizable modules tailored to scientists' requirements. It comprises [Generic Elements](user/elements), [Segments](designer/segments), and [Datasets](designer/datasets) organized using Components, presented as layers and fields. Each generic element, segment, or dataset can consist of multiple layers, and within each layer, various fields can be incorporated. This hierarchical structure ensures adaptable and thorough data organization, providing scientists with flexibility and comprehensive management of their information.

## Generic Templates

Explore the available generic templates on **[Template Hub](https://www.chemotion-repository.net/home/genericHub)**. If a user finds one that matches their requirements, they should kindly reach out to the designer of their particular instance.

Moreover, users are welcome to **[contact the Chemotion team](mailto:chemotion-labimotion@lists.kit.edu)** if they wish to share the templates.
