A **Text** type field is used for entering and displaying textual information. Users can use this field to enter any short, written information.

<div align="center">
  <img src={fieldText} alt="LabIMotion - Text Field" />
  <FigCaption text="Text field type" />
</div>

:::tip
Text fields can be used in [Text Formula](text-formula) fields.
:::

## Extra Field Attributes

### Placeholder

A brief example text that is displayed within the field.

### Read-only

This field is non-editable. When in read-only mode, it appears as plain text with a placeholder if available.

### Required

This field must be filled out before saving the form. Please note that this attribute is only available when the Text field is used in the Element.
