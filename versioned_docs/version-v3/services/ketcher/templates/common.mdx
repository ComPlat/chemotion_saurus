# Overview of Common Templates

Global/Common templates are available to use with Ketcher. Common Templates are a list of templates made available by the System Admin for all users.

<video controls>
  <source src={require("@site/static/img/services/ketcher/templates/common/common-templates.webm").default} />
</video>

#### To enable Common Templates for specific users:

Login as admin > [User Management](../../../eln/admin/user-management) > Enable Common Templates option for the User (Shown in the image below).

![Demo](/img/services/ketcher/templates/common/enable-templates.png)
