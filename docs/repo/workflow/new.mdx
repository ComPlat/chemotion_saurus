## Adding data without ELN support

To add data to the repository, the user has to follow five steps:
Users may have a look at this [YouTube video](https://youtu.be/TSAuiqdkM4Y) where the Chemotion team added an example of how to add data after step 5.

(1) create an account

![](/img/repo/workflow/new/3f837263-364d-48a6-871e-2166b9316f61_image_20191030-26466-8zfqg1.png)

(2) select “My DB”
![](/img/repo/workflow/new/3f837263-364d-48a6-871e-2166b9316f61_image_20191030-26466-w4zyo.png)

(3) select “My data”
![](/img/repo/workflow/new/3f837263-364d-48a6-871e-2166b9316f61_image_20191030-26466-11nwkpd.png)

(4) draw a molecule
![](/img/repo/workflow/new/3f837263-364d-48a6-871e-2166b9316f61_image_20191030-26466-3ndp4i.png)

via the editor
![](/img/repo/workflow/new/3f837263-364d-48a6-871e-2166b9316f61_image_20191030-26466-b0ung9.png)

INFO: adding a molecule is only one example. Users can add [reactions](/docs/eln/ui/elements/reactions) as well by selecting reactions and addition of molecules in their function as starting material, reagent or product.

(5) add data
![](/img/repo/workflow/new/3f837263-364d-48a6-871e-2166b9316f61_image_20191030-26466-18i61mi.png)

Add data to the new item (e.g. analysis files) or others via the information fields. Please ensure that the mandatory information is given, otherwise, the submission will not be processed.

## Transfer data from Chemotion ELN

The transfer of data directly from the Chemotion ELN to the repository is the easiest way for users to disclose their data in only a few steps. The transfer of data makes the time consuming upload of data obsolete.

(1) create a personal account in the repository (see issue (1) above)

(2) Select data in ELN
![](/img/repo/workflow/new/3f837263-364d-48a6-871e-2166b9316f61_image_20191030-26466-rzerea.png)

Go to your ELN and select the data (data assigned to molecules or reactions) you want to disclose and select the assign to button.

(3) Assign your data
![](/img/repo/workflow/new/3f837263-364d-48a6-871e-2166b9316f61_image_20191030-26466-1s4g0m0.png)

Assign the data to the collection “chemotion.net”

(4) Transfer your data
![](/img/repo/workflow/new/3f837263-364d-48a6-871e-2166b9316f61_image_20191030-26466-6itukm.png)

Press the cloud button and follow the instructions given in the black box. When transferring data for the first time, the user has to click the cloud button twice. The first time creates a token to transfer data, the second click initiates the transfer.

When the user returns to their account in the repository, the data can be found in the collection “ELN Gate”

(5) Check in Repository
![](/img/repo/workflow/new/3f837263-364d-48a6-871e-2166b9316f61_image_20191030-26466-919en8.png)

### Status Tracking

During the data transfer process, the user will receive the first message with a Job ID in Chemotion ELN once the data has been packed and sent to the Chemotion Repository. After the Chemotion Repository has received the data, the user will receive the second message with the same Job ID. As the import process runs in the background in the Chemotion Repository, the user will receive the third message with the same Job ID once the data has been processed.

### Link Back to ELN

Users can click on the button at the top of the detail page with the tooltip "Go to original ELN xxx," which will directly link back to the original data in ELN.
