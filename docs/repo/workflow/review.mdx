The reviewing of all data will be done after the user's submission (independent of setting an embargo). The submitted data is only visible and accessible to selected members of the Chemotion repository group who will handle the data as confidential information.

The data is checked for formal issues (formatting, purity of the compounds and quality of the spectra) and for plausibility. The plausibility check is supported by automated procedures. After the Chemotion team has checked the data, the user will receive a reviewing protocol including the necessary changes if there are any. The user will receive a notification in the repository UI, and an email will be sent to their contact email address. Please open the given links or open the reviewing protocol in the repository “My DB” area, collection: “reviewing”.

(1) See reviewed items
![](/img/repo/workflow/review/d0139cda-e311-46e9-a0e6-8693fc769f8b_image_20191030-26466-1ih5t53.png)

A list of the user's reviewed submissions is shown; please select the one to edit

(2) Open details panel
![](/img/repo/workflow/review/d0139cda-e311-46e9-a0e6-8693fc769f8b_image_20191030-26466-1hobggu.png)

(3) Open comments
![](/img/repo/workflow/review/d0139cda-e311-46e9-a0e6-8693fc769f8b_image_20191030-26466-ygum3q.png)

Please select the green reviewing button in the details panel. The given comments on the right side of the page can be directly entered to the original submission listed on the left hand side.

(4) resubmit review
![](/img/repo/workflow/review/d0139cda-e311-46e9-a0e6-8693fc769f8b_image_20191030-26466-1nbma6w.png)

Please answer to the comments of the referees in brief. Users may access the comment: functions via -> review (1) -> type "reviewed (2)" -> click speech bubble (3)

A brief info such as "done", "can't it for this and that reason" or similar is appreciated.
![](/img/repo/workflow/review/d0139cda-e311-46e9-a0e6-8693fc769f8b_image_20200412-31979-xaj9ba.png)

If all changes are complete and the user has commented on the referees' comments, please select the button submit (4) to send the changes and comments to the referees. In case everything is corrected, the submission proceeds to the publication (or will be set on hold for embargoed submissions). If another revision is needed, the Chemotion team will let the user know by notification and email.
