# Third Party Apps

![adminui-3rd-party-app](@site/static/img/eln/admin/3rd-party-app.png)

The Admin can register third-party apps. The ELN users are then able to send attachment files directly from their ELN session to a registered app, as well as getting processed files back and directly uploaded to the same location as the original file in the ELN.

To register an app, the URL of the app is needed. The ELN server and the app must be network-accessible to each other for file transfers to work.
The `name` entered will be displayed to the user (unique, maximum 100 characters). The URL must be unique, start with `http://` or `https://`, and not exceed 100 characters.

A MIME type filter ensures that the app option is only shown to the user for files with compatible types. If the file type does not match the filter, the app option will be hidden. Examples (do **not** use spaces after commas, because entries are split on `,` without trimming whitespace, and use MIME types rather than bare extensions):

- Enter `*` to allow sending any file to the app.
- Enter `image` to allow any image type, such as `image/png` or `image/jpeg`.
- Enter `image/png,text/csv` (without spaces) to restrict sending to PNG images and CSV text files.

When an application is opened from an attachment, Chemotion ELN issues a signed JWT token valid for 48 hours and appends the callback URL (`?url=...`). The external app can read the file via `GET` and submit processed results back to the Chemotion ELN dataset via `POST`.

> [OpenStats](https://github.com/ComPlat/OpenStats) is an example application that has been integrated with the ELN, for more see [OpenStats](../../services/third-party-apps/OpenStats) documentation.
