An administrative interface is available for managing users, groups, and system settings. This functionality is restricted to users with administrative privileges; an admin account opens directly into this interface and does not have access to the `/mydb` workspace.

## Overview

![AdminUI](@site/static/img/eln/admin/overview.png)

The administration interface is organized into the following sections:

- **Dashboard** — server disk usage and the default user allocated space.
- **User Management** — create, edit, lock/unlock, (de)activate and restore user accounts, set disk quotas and grant privileges (see [User Management](admin/user-management)).
- **Devices** — register and manage [devices](admin/remote-devices).
- **Groups** — create and manage [groups](admin/groups) of users.
- **UI features** — enable or disable [interface features](admin/features).
- **Text Templates** — manage global [text templates](ui/text-templates).
- **Message Publish** — broadcast messages to users.
- **Load OLS Terms** — load [ontology](admin/ontology) terms (e.g. CHMO, RXNO).
- **Delayed Jobs** — monitor background jobs.
- **ChemSpectra Layouts** — configure [ChemSpectra](admin/chemspectra) data-type layouts.
- **Third Party Apps** — register [third-party applications](admin/third-party-apps).
