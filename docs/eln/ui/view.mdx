The User Interface (UI) offers different options to adjust the active windows, allowing a more convenient organization of the Chemotion ELN content.

### Zoom the whole screen

To change the overall content size, use the zoom function of the browser. The zoom affects all lists and information in the Chemotion ELN.
![Zooming the screen](/img/zoom.gif)

### Hide and show the collection bar

If you do not need the collections for your current work, you can collapse the collection bar with the toggle on its right edge. The resulting view shows the list of elements and the detail modal. If you do not need the list of elements either and only want to edit the detail modal, select the enlarge button within the detail modal to open it as a full-screen window.

![Hiding the collection bar](/img/adjust_collections.gif)

### Adjust the element lists

Each element list shows a default set of columns; others can be enabled using the button at the top of the list. Additional columns can be loaded by dragging element symbols from the grey area to the white area in the selection modal, and unwanted columns can be dragged from the white area back to the grey area. The action is closed by clicking any other item in the Chemotion ELN UI.

![Adjusting the element lists](/img/adjust_lists.gif)

### Adjust the tabs in the detail modal

The detail modal shows a default set of tabs; others can be enabled using the button at the top of the modal. Additional tabs can be loaded by dragging them from the grey area to the white area in the selection modal, and unwanted tabs can be dragged from the white area back to the grey area. The action is closed by clicking any other item in the Chemotion ELN UI.

![Adjusting the detail-modal tabs](/img/adjust_modal.gif)
