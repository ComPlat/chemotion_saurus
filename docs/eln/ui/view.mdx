The [User Interface (UI)](/docs/eln/ui) offers different options to adjust the active windows, allowing a more convenient organization of the Chemotion ELN content.

### Zoom the whole screen

To change the overall content size, use the zoom function of the browser. The zoom affects all lists and information in the Chemotion ELN.
![Zooming the screen](/img/eln/ui/view/zoom.gif)

### Hide and show the collection bar

If the collections are not needed for the current work, users can collapse the [collection bar](/docs/eln/ui/collections) with the toggle on its right edge. The resulting view shows the list of elements and the [detail modal](/docs/eln/ui/details). If the list of elements is not needed either and only the detail modal is to be edited, select the enlarge button within the detail modal to open it as a full-screen window.

![Hiding the collection bar](/img/eln/ui/view/adjust_collections.gif)

### Adjust the element lists

Each [element list](/docs/eln/ui/lists) shows a default set of columns; others can be enabled using the button at the top of the list. Additional columns can be loaded by dragging element symbols from the grey area to the white area in the selection modal, and unwanted columns can be dragged from the white area back to the grey area. The action is closed by clicking any other item in the Chemotion ELN UI.

![Adjusting the element lists](/img/eln/ui/view/adjust_lists.gif)

### Adjust the tabs in the detail modal

The detail modal shows a default set of tabs; others can be enabled using the button at the top of the modal. Additional tabs can be loaded by dragging them from the grey area to the white area in the selection modal, and unwanted tabs can be dragged from the white area back to the grey area. The action is closed by clicking any other item in the Chemotion ELN UI.

![Adjusting the detail-modal tabs](/img/eln/ui/view/adjust_modal.gif)
