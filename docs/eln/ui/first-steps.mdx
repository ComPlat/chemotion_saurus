## Registration

Registration is a necessary step towards using the electronic laboratory notebook (ELN). Please register on the first visit to the ELN. Then use this access data for each subsequent login. The registration page or the login page will always be the first page accessed.

## SciFinder/SciFinder<sup>n</sup> Credential

This step is only required if the user has been granted permission to use the [Search CAS](../ui/details#search-cas) (<Btn mixed={[faSearch, "Search CAS"]} color={"secondary"} />) feature (ELN 1.3+ versions) or the SciFinder tab feature (prior to ELN 1.0.0).
Both of these features query information in SciFinder/SciFinder<sup>n</sup> by using an API.

:::info[Note]

Please note that you must register once with CAS to obtain your personal CAS username and password.

:::

Users can register the SciFindern credential under **Settings**, in its **3rd-party apps & SciFinder** section.

## The First Collection

<video controls>
  <source src={require("@site/static/img/eln/ui/first_steps/first_collection.webm").default} />

A **collection** is a collection of elements ([**Sample**](elements/samples), [**Reaction**](elements/reactions), [**Wellplate**](elements/wellplates), **Screen**, **Research Plan** and others) that is assigned to a project or subproject. Some collections are set up automatically and cannot be removed: **All**, which gathers every element the user owns as a backup, and **chemotion-repository.net** together with **transferred**, which connect the ELN to the Chemotion Repository. The repository collections should not be used in the first Chemotion ELN trials. These are described under [system collections](collections#system-collections). The creation of the first own collection is usually the first step in the Chemotion ELN and allows users to store their own elements.
For the creation of collections please use the [collection management](collections) via the <Btn mixed={[faCog, "Manage Collections"]} color={"danger"}/> button at the top of the collection bar. Please create a new entry **New Collection** under **My Collections** by pressing <Btn mixed={[faPlus]} color={"success"}/>. Please rename the collection and save it by pressing <Btn mixed={["Save"]} color={"warning"}/>.

:::danger[Caution]

To use the Chemotion ELN functions, a first user-defined collection has to be created!
Please think about a smart structure for your Chemotion ELN and create your first collection!

:::

## Chemotion ELN settings

### Settings: Account and Profile

Version 4 splits these into two sections of the **Settings** sidebar,
**Account** and **Profile**. Between them they allow the user to

- define a reaction label and adjust the counter for reactions
- define a sample inventory label and adjust the inventory label counter for a collection
- change the visibility of labels/numbers for samples
- choose a curation standard for the analytical section
- [add SciFinder/SciFinder<sup>n</sup> credentials](#scifinderscifindern-credential)
- adjust the counter for different elements in the Chemotion ELN
- set up their default structure editor

## Define a sample inventory label and adjust the counter inventory label for a collection

Users can select one or multiple collections and assign a name, prefix, and starting counter to define an inventory label for the collection(s).
Any changes made can be saved by clicking the "Update User Settings" button within the "Sample Inventory Label" box.
Afterward, users can return to the Chemotion main page, where the inventory label will appear next to the collection name in the collections tree.

When creating a new sample, a sample inventory label will automatically be generated with the next available counter number.
Additionally, users can generate a new label for existing samples by clicking the "Auto-Generate Inventory Label" button next to the inventory label field.

### Settings: Authentication token

An **authentication token** lets a script or an external tool reach the ELN's
API as its owner, without a browser session. Tokens are new in version 4.0 and
are managed under Settings → **Account** → **Authentication Token**, below the
two-factor authentication card.

Creating a token requires **two-factor authentication to be enabled**. Without
it, the card shows only a notice and no token can be created.

To create one, press **New Auth token**, give it a name and a lifetime between
1 and 600 days — 30 by default — and confirm with a one-time code from the
authenticator app. Revoking a token asks for a code in the same way.

:::caution[A token is shown once]

The token is displayed only on the screen that creates it, and cannot be
recovered afterwards. The ELN stores a fingerprint of it, not the token itself.
A lost token has to be revoked and replaced.

Tokens begin with `chemtoken_`. They act with the full rights of their owner on
every API endpoint, so they belong in a password manager or a secrets store,
never in a shared script or a repository.

:::

Listed tokens show their name and expiry. A revoked token stays in the list,
marked **REVOKED**, until it would have expired; an expired one disappears.
Revoking takes effect immediately and cannot be undone.

Administrators cannot see or revoke another user's tokens. Deleting the user
account removes them.

To use a token, send it as a bearer token:

```sh
curl -H "Authorization: Bearer chemtoken_..." https://chemotion.dept.uni.de/api/v1/users/current
```
