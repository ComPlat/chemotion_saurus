The calendar can be used to organize a variety of events for users, including events for shared [collections](collections), and individual elements within the Chemotion ELN.

## Accessing the calendar

The calendar can be accessed in 2 ways:

1. The `Calendar` button in the [top bar](.#top-bar)
2. Within an element's header

![Calendar Buttons](/img/eln/ui/calendar/calendar_buttons.png)

Element specific events can be created for the following elements:

- [Samples](elements/samples)
- [Reactions](elements/reactions)
- Screens
- Research Plans

## Calendar features

### Header

The calendar can be moved around the Chemotion ELN window by clicking on the header.
The header holds:

- New Event (creates an event starting now, lasting an hour)
- Show entries (toggles visibility of shared collection events in main calendar / all user events in element specific calendar)
- Filter buttons for element type, calendar type and status — each a checklist with a **Clear** option, listing only the values actually present. The element-type filter appears on the main calendar only
- Full screen
- Lock calendar (keep calendar open whilst using Chemotion ELN)
- Close calendar

### Main Toolbar

The main toolbar allows users to change the calendar view, and move back and forth.

The user can select between 5 different views:

1. Month
2. Week
3. Work Week
4. Day
5. Agenda — shows a single day, with its date and a **Today** badge, listing date, time, event name and description. **Show past events** reveals the ones already finished; Today, Back and Next move a day at a time.

The main calendar shows all user created events / shared collection events.
![Main Calendar](/img/eln/ui/calendar/calendar.png)

An element specific calendar shows its own events / all user created events.
![Element Calendar (Sample)](/img/eln/ui/calendar/sample_calendar.png)
![Element Calendar (Sample) with user events toggled](/img/eln/ui/calendar/sample_calendar_with_user_events.png)

### Events

#### Creating events

Events can be created by clicking anywhere within the calendar.
The following event details can be designated:

- Title (required)
- Description
- Type
- Status — To Be Done, Follow Up, On Hold or Done
- Notify Users
- Duration (defaults: 24 hours if creating in month view / 15 minutes)

When an existing event is edited, neither its start nor its end may be moved
into the past, and the end must stay after the start; changing the start shifts
the end to keep the length. Events created by someone else open read-only,
showing who organised them and who was notified.

Editing the notified users notifies only those newly added. Times in calendar
notifications are shown in the reader's own time zone.

Default event types:

- Reservation
- Duration
- Handover (screen, research plan)
- Reminder (sample, reaction, research plan, screen)
- Report (sample, reaction, research plan, screen)
- Meeting
- Maintenance
- Availability
