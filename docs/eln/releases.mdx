The ELN follows the [semantic versioning](https://semver.org/) scheme. We strive to make releases on a regular basis. However, not all releases are packaged for external releases. After a round of feedback from internal users at KIT, only versions that are considered stable are released via the [chemCLI](install_configure/ChemCLI) tool.

## Latest Releases

Latest releases of the ELN, that are currently supported, are:

### Version 4

#### Version 4.0.0

Version 4.0.0 reworks how collections are shared. This is a **breaking change**: the two
former mechanisms — shared collections and *synchronized* collections — are replaced by a
single sharing model, and the permission levels were renamed and reordered.

What this means in practice:

- **Every collection has exactly one owner.** Existing collections are migrated
  automatically.
- **There is one kind of share.** A share grants access to your own collection, and the
  people you share it with see that collection live, under **Shared with me**. Synchronized
  collections are gone, because every share now behaves the way they did.
- **Permission levels form a strict ladder**: *Read elements* → *Edit elements* → *Add
  elements* → *Remove elements* → *Manage shares* → *Pass ownership*. Existing shares are
  remapped automatically and are never raised to a more powerful level than they held
  before, so nothing needs to be re-shared.
- **Only an element's owner can destroy it.** A collaborator with *Remove elements* unlinks
  an element from the shared collection instead of deleting it.
- **Ownership can be passed on**, as a two-step offer and acceptance: the owner offers
  ownership, and the recipient confirms with **Take ownership**.
- **"Remove from all Collections" no longer deletes globally.** It unlinks the selection
  from your own collections and deletes only the elements left in no collection at all.

Collections that used to appear in the former *My shared collections* branch are gathered
under an ordinary collection named **My projects with others** during the upgrade.

See [Collections](ui/collections) and [Sharing Collections](ui/collections/sharing.mdx) for
the full description, and the detailed release notes for version 4.0.0
[here](https://github.com/ComPlat/chemotion_ELN/releases/tag/v4.0.0).

### Version 3

#### Version 3.0.0 (March 2026)

The new UI comes with several changes such as a new navigation structure, new UI adjustments (e.g. flexible change of the width), and changes to the reactions UI.

The new navigation structure includes a new panel below the summary of collections for collection management, and is drag and drop accessible via new symbols. Inbox, weighing tasks, calendar and notification are moved to collection management.

The reactions UI now provides additional information in the reaction table if more space is given to the reaction panel. The button for changing the reaction scheme information (samples given with name or structure) is moved to the reaction image, and my labels for reactions are now in scheme (not properties tab).
