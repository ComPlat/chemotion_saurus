Hello and thank you for using Chemotion ELN!

For first-time users, the Chemotion team recommends reading the manual before starting work on a project, since it's not always possible to make the functionality of Chemotion ELN self-explanatory. This manual highlights what's necessary to make full use of the ELN's capabilities.

For specific questions, please check out the links below.
They correspond to the chapters of the manual:

- For users who do not know where to start at all, go [here](eln/ui/first-steps).
- For support on how to report and structure data, users can find videos [here](eln/videos).
- Please have a look at the [definition of terms](eln/ui) that the manual uses throughout.
- Users can learn how to adjust their user interface [here](eln/ui/view).
- In the ELN, projects are organized in [collections](eln/ui/collections).
- Please also have a look at [using lists](eln/ui/lists).
- In the Chemotion ELN, users work with elements,
  such as [samples](eln/ui/elements/samples), [reactions](eln/ui/elements/reactions) and [wellplates](eln/ui/elements/wellplates).
- [Detail panels](eln/ui/details) provide information about [structures](eln/ui/details#details-panel-for-samples), [reactions](eln/ui/details#details-panel-for-reactions) and [wellplates](eln/ui/details#details-panel-for-wellplates).
- Learn about toolbar functions [here](eln/ui/toolbar).
- Questions about how to enter molecules into the Chemotion ELN will be answered in this [chapter](eln/ui/ketcher).
- With Chemotion ELN, users can [scan](eln/ui/barcodes#scan-barcodeqr-code) and [generate](eln/ui/barcodes#generate-barcodeqr-code) QR codes as well as bar codes.
- To create an inventory for a group, follow this [link](eln/ui/inventory).
- The access of analytical data in the Chemotion ELN is done via ChemSpectra which is explained [here](services/chemspectra).
- Moreover, users can customize the ELN using [generic elements and segments](eln/admin/generic-config).
- [Here](eln/troubleshooting), users can find solutions for common issues.

While reading the manual, please mind the hints and instructions that are identified by the following symbols for **Caution** and **Recommendation**.

:::

:::info[Recommendation]

:::

:::

:::note[Links]

:::

All terms in this manual that are written in ** boldface ** correspond to terms that are used in the user interface.

If questions are not answered in the manual, please use the Helpdesk(https://chemotion.net/helpdesk) to contact the team!
The ELN team is available for questions and assistance, but it assumes that users are familiar with this manual and, in particular, with the highlighted **Cautions** and **Recommendations**.
