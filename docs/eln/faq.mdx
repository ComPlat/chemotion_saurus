### Access

#### Where can I try Chemotion ELN?

A [test version](https://demo.chemotion.ibcs.kit.edu/) is available for demonstration purposes and time-limited applications. It is freely available to all interested users. The test version enables users to evaluate the latest version of Chemotion ELN without prior installation with regard to its suitability for their individual application. The Chemotion team asks users not to do any logging via the test version since data may be lost due to system updates and database changes. Some functions cannot be accessed in the test version, e.g. the SciFinder plug-in.

#### How can I install Chemotion ELN?

For routine use in operations, Chemotion ELN can be installed on IT facilities of a group/institution/university. Please refer to the [Installation Guide](install-configure) for more.

#### Is it possible to use Chemotion ELN offline?

- **Answer:** Chemotion ELN is a web based application that can only be used over a network connection. Please make sure to use Chrome browser.

#### Is there a standalone version of Chemotion ELN?

- **Answer:** Currently there is no standalone version of Chemotion ELN, and there are no plans to have it in the near future.

#### What are the prerequisites for proper Chemotion ELN use?

- **Answer:** A standard laptop/desktop, internet connection and Chrome browser are sufficient. Please do not use other browsers as they seem to function, but this functionality is never complete and/or tested.

### Collections

#### How to share elements from Chemotion ELN with others? Especially to limit the access of trainees, for role assignment and access rights?

- **Answer:** Everyone is the owner of their account. Accounts are not shared and can't be controlled by, e.g., a supervisor, but they can be deleted by Chemotion admins. However, sharing of certain elements of the Chemotion ELN, and assigning roles is still possible through collections sharing and synchronizing. For more details on those two functions, please refer to [Shared collections](ui/collections#shared-collections) and [Synchronized collections](ui/collections#synchronized-collections).

#### How many people can work on a shared or synchronized collection at the same time?

- **Answer:** Any number of users in the real world can work simultaneously on a shared or synchronized collection.

#### Why can’t I find the collection that I have created in the collections bar?

- **Answer:** When creating a collection, users have to make sure to press <Btn mixed={["Update"]} color={"warning"}/> in their collection management.

#### Why can’t I find the elements I have created in a collection when I look in its upper collection?

- **Answer:** Sub-collections are not mirrored in the upper collection, they are rather just an optical structuring tool.

#### Why can’t I see the elements added by my partner to the shared collection?

- **Answer:** In a shared collection, only changes to existing elements are displayed to users. Elements added after sharing to the original collection will not be considered. To see new elements, use collection synchronization.

### Samples

#### Why can’t I see any other tab in the sample’s details modal rather than **Properties**?

- **Answer:** The **Properties** tab is the only tab shown by default in the [details modal](ui/details). The other tabs are hidden to give the user the space to organize their windows. Users can add or remove tabs as they wish from their details modal as explained [here](ui/view#adjust-the-tabs-in-the-detail-modal).

#### Why can’t I add samples to the collection?

- **Answer:** Make sure that a collection has already been selected and that the **All** collection is not active. No action can be performed in the **All** collection because it is a kind of backup.

#### Why has the name of my sample changed automatically?

- **Answer:** The [sample](ui/elements/samples) is mostly a product from a [reaction](ui/elements/reactions). The Name field within the product sample Properties tab is overwritten because it is required to generate a product name.

#### I have copied a sample, and all its information except its structure is lost, why?

- **Answer:** With the Copy sample action, only the molecular structure of the sample is copied; all other information is not available and will not be adopted. Only the general information available from the molecular structure, e.g. molecular weight, are transferred. For the other details, such as the concentration and others, please use the **Split** action.

#### Why can’t I see all the samples I have created in sample list?

- **Answer:** If a sample has been created in an indirect way, e.g. from within a reaction, it might not appear in the samples list. In general, Reactants and Solvents don’t appear in the list, while samples that have been created as Starting material or as a Product are listed.

#### How can I add a **Reactant** to the samples list?

- **Answer:** **Reactant**s don’t appear in the samples list. To see them there, change their status from **Reactant**s to **Starting material**.

### Reactions

#### How can I add coefficients to balance my reaction?

- **Answer:** Yes, coefficients to balance the equation can be added in the reaction table (since v1.4.0). Those coefficients are not yet displayed in the reaction image, but the Chemotion team is working on this.

### Tracking Changes and Making Backups

#### How are changes in data (e.g., time, author) tracked? Is there a versioning / time-stamping / auditing system in place?

- **Answer:** The Chemotion team is currently working on versioning and auditing systems.

#### Is it possible to retrieve deleted data e.g. in case of accidental deletion of a collection?

- **Answer:** Most of the entries are soft deleted (marked as deleted in the database but are not removed). However, there is no user interface to restore them easily. Please pay attention that deleting a collection does not remove its elements, it rather removes the association between the elements and the collection. Elements can still be picked out individually from **All** collection to (re-create) a new collection. If for some reason all data is lost or the ELN needs to be restored to a previous state, it is necessary to have backups in place. For this reason, the Chemotion team recommends creating a [backup plan](install-configure/manual-install.mdx#backing-up-and-restoring-your-data) and automating a regular backup process.
