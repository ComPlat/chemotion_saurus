The **Drag Sample** type features an icon with drag-and-drop functionality, allowing users to seamlessly add a [sample](/docs/eln/ui/elements/samples) to a [generic element](/docs/labimotion/designer/elements) by simply dragging and dropping it. Upon adding, the sample image is displayed for easy reference.

An icon with drag & drop function to let the user add a sample. It will display the sample image after being added.

:::
