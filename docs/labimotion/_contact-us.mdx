### Feature Requests

For innovative feature requests, the Chemotion team encourages users to create a post on the **[Discussion](https://github.com/LabIMotion/labimotion/discussions)** board. This method provides the core team with a more accurate gauge of the features in high demand, which is superior to GitHub issues, as the latter can be more challenging to prioritize.

The Chemotion team kindly requests that users refrain from submitting Pull Requests for new features, especially substantial ones, as there may already be ongoing work or such features may be part of future plans. The first step should be to initiate a conversation with the team!
