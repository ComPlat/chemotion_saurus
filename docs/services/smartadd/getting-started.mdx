# Getting Started with SmartAdd

Welcome! This guide gets users up and running with SmartAdd. It is easier than it appears.

## What You'll Need

Don't worry - the requirements are simple:

- **Modern Browser**: Chrome, Firefox, Safari, or Edge (any recent version works great)
- **Your Data**: Analytical data files or ZIP archives of datasets
- **That's It!**: No installation needed. SmartAdd runs right in the browser and automatically saves data in browser storage, so users lose nothing when they refresh the page. 

## Let's Get Started

### 1. Open SmartAdd

Just open SmartAdd in a browser. A simple, clean interface appears:
- **Left Side**: Where users upload files and find action buttons
- **Right Side**: The workspace with the tree view and editor, and some action buttons

### 2. Upload Your Data

Users can upload data in two ways - pick whichever feels easier:

#### Individual Files
Just drag the analytical files into the "Drag files here" area. That's it! SmartAdd processes them instantly and shows the organized structure.

#### ZIP Archive (We Recommend This!)
Got a bunch of files? Package them in a ZIP first, then drag the ZIP into SmartAdd. It automatically extracts and organizes everything.

:::tip[Why ZIP Files?]
ZIP archives make life easier when working with:
- Lots of files at once
- Complex folder structures to preserve
- Large datasets (uploads faster as a single file)
- Related files that need to stay together
:::

### 3. Explore Your Data

Once the files are uploaded, they appear in the **input list on the left side**:
- All uploaded files appear here, organized in a simple list
- This is the file inventory - ready to be assigned to [samples](../../eln/ui/elements/samples) and [reactions](../../eln/ui/elements/reactions) analysis/datasets
- Users drag files from here to the assignment tree on the right

On the **right side**, users build the collection structure:
- Use "Add Sample" and "Add Reaction" buttons to create the hierarchy
- The hierarchy works like this: **Reactions** → **Samples** → **Analyses** → **Analysis** → **Dataset** → **Files**
- Drag files from the left input list to assign them to samples and reactions on the right

It's intuitive - just click around and explore!

### 4. Make Your First Edit

Ready to edit something? Here's how:
1. Click on any sample, reaction, or analysis in the tree
2. A properties panel appears with editable fields
3. Click on any field and start typing
4. Changes save automatically - no "Save" button needed!

**Enhanced Editing Features:**
- **Rich Text Editor**: Description fields use the Quill editor with formatting tools (bold, italic, lists, headers)
- **Structure Editor**: Click "Draw Structure" to use the integrated Ketcher molecular editor for creating MOL files
- **Real-time Validation**: SMILES and MOL files are validated as the user types, with instant feedback
- **Smart Auto-Save**: Changes are automatically saved with debouncing to prevent data loss

### 5. Send Your Data to Chemotion

Once the organized data is ready, users have two ways to export:

#### Download as ZIP
The classic approach:
1. Review everything looks good
2. Click **Download as ZIP**
3. Save the file
4. Upload it to Chemotion whenever you're ready

#### Direct Upload (The New Way!)
Skip the middleman:
1. Click **Upload to Chemotion ELN**
2. Enter the Chemotion server URL
3. Log in with the appropriate credentials
4. SmartAdd sends everything directly - done!
