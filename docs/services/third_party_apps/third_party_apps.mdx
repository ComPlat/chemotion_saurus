title: Setup a Third Party App
sidebar_position: 3
---

To set up a third-party application (TPA) in Chemotion ELN, you need administrator access to the ELN administration interface.
The configuration is straightforward and allows external tools—such as OpenStats—to be integrated into your workflow.
First, navigate to the ELN Administration section in Chemotion.
In the left-hand menu, select “Third Party Apps.” This section lists all currently configured external applications and allows you to manage or add new ones.
To create a new TPA, click the “New ThirdPartyApp +” button.
This opens a form titled “Create new third party app.” Here, you must provide the following information:

* Name: Enter a descriptive name for the application (e.g., OpenStats or AwesomeApp). This name will be displayed in the ELN interface.
* IP address: Specify the URL where the external application is hosted. This is typically a full address including protocol and port, for example http://localhost:3838 for a locally running Shiny app.
* File types (MIME): Define the file types that should be sent to the application. These are given as comma-separated MIME types or extensions (e.g., text, csv). This determines which data formats the ELN will forward to the TPA.

After filling in the required fields, click “Create +” to register the application. Once created, the TPA will appear in the list of available third-party apps and can be edited or removed if necessary.

With this setup, Chemotion ELN can send compatible datasets directly to the configured application, enabling seamless integration into external analysis workflows such as OpenStats.
