## Enable/Disable users as ChemConverter Administrator

To assign the ChemConverter Administrator role, navigate to the [User Management](../../eln/admin/user-management) menu, select the desired user, and click on **Enable Converter profiles editing for this user** <FontAwesomeIcon icon={faHourglassHalf} />.
If the button is green, the user has Converter management permission; otherwise, they do not.

<div align="center">
  <img src={permissionManagement} alt="UI Feature" width="800" />
</div>

When the administrator clicks on the **Enable Converter profiles editing for this user** button, a message confirms: _'Converter-profiles editing has been enabled for user `<id>`'_.
Likewise, clicking the button again to revoke converter management permission confirms: _'Converter-profiles editing has been disabled for user `<id>`'_.

:::info[Permissions]

The ChemConverter Administrator permission is granted by the system administrator.

:::
