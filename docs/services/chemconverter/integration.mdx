# ELN integration

The Chemotion Converter is integrated as a background process, so the user will not notice it except by the presence of additional files alongside the original.
When using a file from the [inbox](/docs/eln/ui/inbox) that comes from an [integrated device](/docs/eln/devices), the user should use the ChemConverter-produced file (if a conversion is necessary / possible for this kind of file).
To do so, just drag & drop it from the inbox to the wanted field of the ELN GUI.
The exact workflow is shown in the animated picture.

![Workflow for converted files from integrated devices](/img/services/chemconverter/integration/ConvertedFileFromDevice.gif)


:::warning[warning]
Note that drag-n-dropping only the original file from the inbox into an analysis will not trigger the converter if the converter has already processed it and deposited the resulting zip alongside the original.
To keep the original and trigger the spectra view, the user should move both files into an analysis dataset.
