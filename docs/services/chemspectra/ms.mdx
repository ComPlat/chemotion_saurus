:::info[Supported file formats]

For Mass spectrum analysis, the Chemotion team currently supports [JCAMP-DX files](https://iupac.org/what-we-do/digital-standards/jcamp-dx/) (\*.jcamp, \*.dx, \*.jdx), \*.RAW (Thermo Fisher), \*.mz(X)ML, zip (in [BagIt](https://en.wikipedia.org/wiki/BagIt) format) files.

:::

1. To upload and view their data, users can follow [this instruction](../chemspectra#how-to-use-chemspectra).
