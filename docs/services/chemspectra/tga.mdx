:::info[Supported file formats]

For Thermogravimetric analysis, the Chemotion team currently supports [JCAMP-DX files](https://iupac.org/what-we-do/digital-standards/jcamp-dx/) (\*.jcamp, \*.dx, \*.jdx), zip (in [BagIt](https://en.wikipedia.org/wiki/BagIt) format) files.

:::

1. To upload and view their data, users can follow [this instruction](../chemspectra#how-to-use-chemspectra).

2. Hover your mouse over the spectrum to view the temperature and weight. Using the tools bar to zoom in/out, add peaks:
