This repository can be used directly without any preparations. Nevertheless, a few preparations help to organize the process efficiently.

## Where the settings live

In version 3 the account screens are reached from the **user menu** at the right of the navigation
bar. Two entries matter for publishing:

- **Settings** — split into **Account** (log-in, password, two-factor authentication, and deleting the
  account), **Profile** (ORCID iD), **3rd-party apps & SciFinder**, and **Affiliations**.
- **My Collaboration** — the people who can be named as authors or reviewers, and the group lead(s).

## ORCID

(1) Please register for an ORCID here if you don't have an ORCID yet. It's fast and easy. <br/>
https://orcid.org/<br/>
(2) Please enter your ORCID in the repository under **Settings › Profile**.

The iD must be in the format `0000-0000-0000-0000`. It is validated against orcid.org when
**Validate & Save ORCID** is pressed, and the account name must match the name on the ORCID record.

## Affiliations

Affiliations are maintained under **Settings › Affiliations**. Keeping them current matters: the
submission dialogs read this list when attributing a contributor's work, and the
[affiliation numbering](workflow/affiliation) on a publication comes from it.

## Add your collaborators

Collaborators are needed to assign other people as authors to a contribution. To publish data with others as authors, those people need to be on the collaborator list.

Open **My Collaboration** from the user menu. People can be added by ORCID iD, or by name and email.

### By ORCID iD

:::warning[Attention]

Pressing **Find** adds that person to the collaborator list straight away — there is no separate
confirmation step on this path. Check the iD before pressing it.

:::

### By name or email

Searching by **first name, last name or email** returns a *Search Results* table of everyone
registered in the Repository who matches, with their department, organization and country — so
namesakes can be told apart. Nothing is added until the **Add** button is pressed on a row.

## Assign Group Lead

Group lead(s) can be assigned using the **My Collaboration** feature. Once assigned, they are automatically added as reviewers and co-authors by default upon submission, and can still be removed before submitting.

The first column of the collaborator table carries the control: **Set Lead** on a row that is not yet
a lead, and a highlighted **Lead** badge on the rows already assigned.
